# Flujo de entrega (Claude Code hace el trabajo; vos aprobás)
1. Llega pedido → pegá en la sesión: "PEDIDO: <texto del cliente> + adjunto". 
2. Claude: produce entregable en agencia/pedidos/<id>/ + notas al cliente (EN/ES) + checklist de verificación.
3. Vos (5 min, celular): revisás notas y 2-3 puntos del checklist → "OK entregar".
4. Entregás en la plataforma pegando las notas. Actualizar MEMORY.md (Métricas + Log).
Reglas: no prometer plazos <24h; pedir datos de ejemplo, nunca credenciales; si el pedido supera el alcance → ofrecer custom offer.
Ahorro de tokens: un pedido = una sesión; usar Sonnet para traducciones/fórmulas simples; Opus solo para Apps Script complejo.
